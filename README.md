# Разработка онлайн-школы

## Описание проекта

Данный проект представляет собой платформу онлайн обучения разработанную с применением Django REST framework. 
Он включает в себя Django-проект, функционал которого релизован в приложении lms. 

Цели проекта:
1) Создание моделей пользователей, курсов и уроков, организация связи между ними.
2) Реализация CRUD для модели курсов с помощью Viewsets.
3) Реализация CRUD для модели уроков с ипользованием Generic-классов.
4) Настройка маршрутизации для этих контроллеров.
5) Настройка подключения в проекте к  СУБД PostgreSQL, сокрытие чувствительных данных.
6) Создание базы данных и выполнение миграций с полями моделей.

## Документация API

Документация для данного API сформирована автоматически и предоставляется через интерфейс Swagger. 
Для локального доступа к документации запустите сервер разработки и перейдите по следующему URL: http://localhost:8000/swagger/

## Установка

1. Для начала работы клонируйте репозиторий: git clone https://github.com/SuperZebrocat/OnlineSchool.git
2. Установите необходимые зависимости: pip install -r requirements.txt
3. Локально приложение доступно по адресу http://localhost:8000/

## Развертывание на удаленном сервере

1. Установите на удаленном сервере Docker и Docker Compose.
2. Для контейнеризации приложения используйте Docker и Docker Compose, сборка контейнеров осуществляется по инструкции в Dockerfile и docker-compose.yaml.
3. Деплой приложения происходит автоматически при выполнении команд git push или pull request.
4. Деплой осуществляется при предвартельном линтинге кода (flake8) и прохождении тестирования - данные шаги проверки кода описаны в файле ci-cd.yaml. 
5. Для входа на удаленный сервер выполните команду ssh -l ekatesting 158.160.185.72.
6. Настройте все необходимые переменные окружения, в корне проекта создайте файл .env для хранения чувствительных данных.
7. Проверьте логи контейнеров для диагностики возможных проблем: docker-compose logs
8. После успешного развертывания вы сможете получить доступ к API по адресу: 158.160.185.72
